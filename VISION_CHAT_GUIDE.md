# AI Vision Chat - Техническое руководство

## Обзор функциональности

Интегрированный чат позволяет проводить глубокий анализ визуального контента с использованием современных Vision-моделей. Система поддерживает отправку комбинированных сообщений, состоящих из текста и изображений.

## Функции и возможности

### 1. Выбор и обработка изображений
На мобильных устройствах Android используется системная галерея. При первом вызове приложение запрашивает необходимые разрешения на чтение медиафайлов. На настольных системах задействуется нативный проводник операционной системы. 

### 2. Типы запросов
- Текстовый анализ: нейросеть отвечает на вопросы по содержанию изображения.
- Решение задач: AI может распознавать рукописный текст и помогать в решении образовательных задач.
- Программный анализ: возможность проверки кода по скриншотам из IDE.

### 3. Интеллектуальное управление моделями (Fallback)
Для обеспечения бесперебойной работы реализована система автоматического переключения между моделями. Если основная модель (Gemini 2.0 Flash) достигла лимитов или недоступна, запрос автоматически перенаправляется на альтернативные системы (Qwen VL или Llama Vision).

## Требования для работы

- Наличие корректного API ключа в настройках приложения.
- Активное Интернет-соединение.
- Современные версии Android (начиная с 6.0 и выше) или настольная ОС с поддержкой Python 3.10.

## Инструкция по использованию

1. Запустите SmartTest и перейдите в раздел AI чата.
2. Используйте кнопку прикрепления файла для выбора изображения.
3. Введите ваш вопрос в текстовое поле. Поле может оставаться пустым, если требуется простое описание картинки.
4. Отправьте сообщение и ожидайте ответа. История переписки сохраняется в рамках текущей сессии.

### Размер изображений
- Изображения конвертируются в base64
- Рекомендуемый размер: до 2-3 MB
- Большие изображения могут вызвать таймаут

### Форматы
- Поддерживаются: JPG, JPEG, PNG, GIF, WEBP, BMP
- MIME type определяется автоматически
- URL изображения должен быть доступен по HTTP/HTTPS

## Решение проблем

### File picker не открывается (Android)
1. Проверьте разрешения в настройках Android
2. Переустановите приложение
3. Используйте fallback: введите путь `/sdcard/DCIM/...`

### Изображение не отправляется
1. Проверьте API ключ в настройках
2. Проверьте интернет-соединение
3. Проверьте формат файла (должен быть JPG/PNG/GIF/WEBP)
4. Проверьте размер (большие файлы могут не обрабатываться)

### 429 Too Many Requests
- Подождите несколько минут
- Система автоматически попробует другие модели
- Если все модели заняты - подождите 10-15 минут

### Ошибка "API ключ не настроен"
1. Откройте главный экран → Настройки (иконка справа)
2. Вставьте API ключ OpenRouter (начинается с `sk-or-`)
3. Нажмите "СОХРАНИТЬ"
4. Попробуйте снова
