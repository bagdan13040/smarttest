# Система дорожных карт обучения (Roadmap)

## Описание системы

Система дорожных карт позволяет пользователю получить структурированный план изучения любой темы. Вместо одного урока генерируется последовательность из 5-8 модулей, выстроенных в логическом порядке с учетом зависимостей (prerequisites).

### Реализованные возможности

1. Генерация учебного плана в модуле llm.py:
- Функция generate_learning_roadmap создает детализированную структуру курса.
- Система автоматически расчитывает взаимосвязи между модулями.
- Поддерживается настройка уровня сложности (начинающий, средний, эксперт).
- Реализована интеграция интересов пользователя в каждый шаг обучения.

2. Пользовательский интерфейс:
- Экран RoadmapScreen визуализирует программу в виде интерактивной сетки.
- Прогресс отображается цветами: серый (заблокировано), синий (доступно), зеленый (пройдено).
- Линии связей между модулями отрисовываются динамически через Kivy Canvas.
- Автоматический layout подстраивается под размер экрана устройства.

3. Управление прогрессом:
- Состояние обучения сохраняется в файле roadmaps.json.
- Приложение запоминает, какие модули были пройдены, и открывает доступ к следующим.
- Весь прогресс сохраняется автоматически после завершения тестов в рамках модуля.

---

## Технические подробности

### Логика графа
Модули без предварительных условий (prerequisites) доступны для изучения сразу. Модули с зависимостями активируются только после того, как все родительские темы будут помечены как завершенные. Линии отрисовываются в методе update_canvas_lines для обеспечения корректности на разных разрешениях экрана.

## Как использовать

1. На экране Поиск выберите режим Программа обучения.
2. Введите тему и уровень сложности.
3. Система сгенерирует план и отобразит его в виде карты.
4. Кликните на доступный модуль для просмотра тем и начала обучения.
5. После прохождения теста в модуле, его статус обновится на карте.
- `google/gemini-2.0-flash-exp:free`
- Хорошая структурированность ответов
- Логическое выстраивание зависимостей

- Валидация структуры ответа

### В приложении:

- **Прокрутите** - посмотрите все модули
- **Кликните на модуль** - откроется popup с деталями
- **Нажмите "Начать изучение"** - запустится генерация первой темы

### Программно:

```python
from llm import generate_learning_roadmap

# С API
roadmap = generate_learning_roadmap(
    topic="Python",
    goal="веб-разработка",
    level="начинающий",
    api_key="sk-..."
)

# Без API (mock)
from llm import generate_mock_roadmap
roadmap = generate_mock_roadmap("Python", "веб-разработка", "начинающий")
```

## 🐛 Troubleshooting

### Проблема: Request timeout

**Причина:** LLM генерация занимает >120 секунд

**Решения:**
1. Подождите - urllib fallback попробует снова
2. Упростите тему (короче = быстрее)
3. Используйте mock: `generate_mock_roadmap()`

### Проблема: 429 Too Many Requests

**Причина:** Превышен лимит запросов API

**Решения:**
1. Подождите 1-2 минуты
2. Используйте другой API ключ
3. Для тестов: `generate_mock_roadmap()`

### Проблема: Модули не отображаются

**Проверьте:**
1. Логи `[LLM]` - успешна ли генерация?
2. `roadmaps.json` - сохранён ли roadmap?
3. `app.current_roadmap` - загружена ли карта?

**Отладка:**
```python
# В консоли Python
from llm import generate_mock_roadmap
rm = generate_mock_roadmap("Test", level="начинающий")
print(len(rm['modules']))  # Должно быть 5-8
```

### Проблема: Линии связей не видны

**Причина:** Canvas рисуется ДО добавления виджетов

**Решение:** В `_create_roadmap_layout()` порядок:
1. Создать все узлы
2. Потом рисовать линии в `canvas.canvas.before`
