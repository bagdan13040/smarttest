# Руководство по отладке Android-версии

## Инструментарий для отладки

Для выявления и устранения ошибок в мобильной версии SmartTest рекомендуется использовать стандартные инструменты разработчика Android.

## Основные этапы диагностики

### 1. Сбор системных логов (Logcat)
Система Logcat позволяет просматривать вывод `print()` из Python-кода и сообщения от Kivy-движка.
- **Команда**: `adb logcat -s python`
- **Анализ**: Ищите теги `[LLM]`, `[Kivy]` и `[INFO]`. При возникновении ошибки (Traceback) она будет выведена полностью в консоль.

### 2. Проверка сетевой связности
Если приложение сообщает об отсутствии интернета:
- Выполните `adb shell ping -c 3 8.8.8.8` для проверки базового доступа.
- Проверьте доступность API OpenRouter: `adb shell curl -I https://openrouter.ai/api/v1/chat/completions`.

### 3. Отладка хранилища данных
Для проверки корректности сохранения настроек и прогресса:
- Проверьте наличие файлов: `adb shell ls /data/user/0/org.smarttest/files/` (путь может отличаться в зависимости от package_name).
- Проверьте содержимое `settings.json` на наличие корректного API ключа.

## Типичные сценарии и решения

### Приложение закрывается при старте
- **Причина**: Отсутствие необходимых библиотек в `requirements` файла `buildozer.spec`.
- **Решение**: Проверьте логи на наличие `ModuleNotFoundError`. Добавьте недостающий модуль и пересоберите проект.

### Зависание на экране загрузки
- **Причина**: Бесконечный цикл в фоновом потоке или блокировка основного GUI-потока.
- **Решение**: Убедитесь, что все сетевые запросы обернуты в `threading.Thread`.

### Ошибки доступа к файлам
- **Причина**: Недостаточные разрешения.
- **Решение**: Проверьте, что в настройках Android приложению выданы права на использование хранилища/медиафайлов.

Если пинг не проходит - проблема в настройках эмулятора.
