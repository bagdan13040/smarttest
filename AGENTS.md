# AGENTS.md - Документация для AI Агентов

## Обзор Проекта

SmartTest - мобильное приложение на Kivy для адаптивного обучения с использованием LLM (Language Model).

### Основная концепция
Приложение генерирует персонализированные учебные материалы и тесты по любой теме, оценивает ответы пользователя через LLM, и адаптирует сложность на основе результатов. Поддерживает как одиночные уроки, так и полноценные Дорожные карты (Roadmaps).

### Технологический стек
- Framework: Kivy 2.3.1 (Python GUI) + KivyMD
- Language: Python 3.10+
- LLM Integration: Пользовательский модуль llm.py (OpenRouter API)
- Storage: JSON-based (JsonStore, courses.json, roadmaps.json)
- Target Platform: Android (с поддержкой Desktop)

## Архитектура Приложения

### Структура файлов
```
main.py               # Основной файл приложения (~5850 строк). Управляет жизненным циклом экранов и асинхронными задачами.
llm.py               # LLM интеграция (1400+ строк). Обрабатывает промпты, делает сетевые запросы и парсит JSON.
courses.json         # Хранилище сгенерированных уроков.
roadmaps.json        # Хранилище дорожных карт и прогресса по ним.
settings.json        # Пользовательские настройки (API ключ, тема).
open_questions_cache.json  # Оптимизация ответов на открытые вопросы.
course_topics.json   # Метаданные изученных тем.
assets/              # Статические ресурсы (PNG/SVG).
```

### Основные компоненты

#### 1. Экраны (Screens)
- MainScreen: Контейнер для трех основных вкладок (Saved, Search, Settings).
- SavedScreen: Список ранее созданных материалов. Поддерживает удаление и повторное прохождение.
- SearchScreen: Интерфейс для формирования запроса к AI. Позволяет выбрать режим (Урок или Карта) и сложность.
- SettingsScreen: Управление API ключом и системными параметрами.
- LoadingScreen: Экран ожидания. Включает в себя динамический список фактов и индикатор прогресса.
- TheoryScreen: Отображение сгенерированного текста. Поддерживает Kivy Markup ([b], [i], [color]).
- QuizScreen: Реализация MC-теста. Автоматически перемешивает варианты ответов.
- OpenAnswerScreen: Индивидуальная проверка знаний через текстовый ввод.
- RoadmapScreen: Визуализатор учебной программы. Отрисовывает связи между темами и блокирует модули до прохождения пререквизитов.
- FinalScreen: Сводный отчет с анализом ошибок (сравнение ответов пользователя с правильными).

#### 2. Хранилища данных

- CourseStorage (courses.json): Сериализует объекты курсов.
- RoadmapStorage (roadmaps.json): Управляет сложными структурами программ.

#### 3. LLM Модуль (llm.py)

Ключевые функции:
- generate_quiz: Формирует теорию (~1000 слов) и 10 вопросов. Обрабатывает контекст интересов.
- generate_learning_roadmap: Создает иерархическую структуру модулей (5-8 штук) с описаниями и зависимостями.
- generate_open_questions: Генерирует 5 контрольных вопросов для глубокой проверки.
- evaluate_answer: Сравнивает ответ пользователя с "notes" (эталоном) и выставляет балл от 0 до 10 с подробным фидбеком.
- chat_with_image: Использует Vision модели для анализа графической информации.

## Потоки Данных

### 1. Создание нового курса/карты
Запрос инициируется на SearchScreen, передается в фоновый поток (threading). llm.py выполняет HTTP-запрос. После получения ответа результат сохраняется в JSON и происходит переход на TheoryScreen.

### 2. Система дорожных карт (Roadmaps)
1. Генератор создает модули с prerequisites.
2. RoadmapScreen отрисовывает их как узлы.
3. Клик на узел проверяет статус зависимостей. Если все пройдено — кнопка Начать изучение активна.
4. После прохождения последнего теста в модуле, его статус в JSON меняется на completed.

## Ключевые Особенности Реализации

### 1. Мульти-модельный Fallback
Система последовательно пробует модели: Xiaomi Mimo, Gemini 2.0, Llama 3.1, Mistral. Это гарантирует ответ даже при технических работах на стороне одного из провайдеров.

### 2. Поддержка Vision
Используется для помощи студенту. Можно сфотографировать условие задачи или график, и AI объяснит решение или задаст уточняющие вопросы.

### 3. Адаптивная сложность
После каждого FinalScreen приложение пересчитывает средний балл. Если он выше 80% за 3 последних урока, сложность по умолчанию в поиске инкрементируется.

## UI/UX Паттерны

### Roadmap Visualization
- Модули отображаются в сетке.
- Связи отрисовываются линиями (Canvas Line).
- Цвета: Серый (не начато), Синий (в процессе), Зеленый (пройдено).

### Асинхронность
Все запросы к API идут через threading, чтобы не фризить UI. Обратный вызов в GUI через Clock.schedule_once.

---

## Типичные Решения

- Таймауты: Увеличены до 120 секунд для стабильности на плохом соединении.
- Unicode-символы: Используется sanitize_unicode в llm.py для замены спецсимволов на понятные Kivy ASCII/простые UTF.
- Android Settings: На Android рекомендуется вводить API ключ через UI (SettingsScreen), так как .env часто не подхватывается.
