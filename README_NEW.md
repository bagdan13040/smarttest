# SmartTest - Новые функции и Быстрый старт

## Основные возможности v1.1

- Roadmaps - создавайте полноценные программы обучения. Система генерирует последовательность тем с учетом их сложности и взаимосвязей.
- Vision Chat - задавайте вопросы по изображениям и скриншотам. Нейросеть проанализирует визуальный контент и даст развернутый ответ или составит тест.
- Интеграция интересов - AI адаптирует теорию под ваши хобби (футбол, игры, музыка). Примеры и аналогии будут связаны с выбранной областью интересов.
- Multi-Model Fallback - если одна модель нейросети недоступна или работает слишком медленно, приложение автоматически переключается на альтернативные варианты (Gemini, Llama, Mistral).

## Структура проекта

- main.py — основной код приложения (UI, логика, хранилище, ~5850 строк). Управляет всеми экранами и асинхронными задачами.
- llm.py — модуль для работы с OpenRouter API (1400+ строк). Отвечает за формирование промптов и обработку JSON ответов.
- courses.json — база данных сохраненных одиночных уроков.
- roadmaps.json — база данных сохраненных учебных программ.
- assets/ — графические ресурсы и иконки приложения.

## 🖥️ Как запустить на Windows

1. Создайте виртуальное окружение и установите зависимости:

```powershell
cd e:\context_study
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

2. Создайте файл `.env` с вашим API ключом:

```bash
OPENROUTER_API_KEY=sk-or-v1-your-key-here
```

3. Запустите приложение:

```powershell
python main.py
```

## 📱 Как собрать для Android

### Требования
- Linux или WSL (Windows Subsystem for Linux)
- Buildozer

### Сборка

```bash
# Установите buildozer (в Linux/WSL)
pip install buildozer

# Очистите старые сборки
buildozer android clean

# Соберите APK
buildozer android debug

# APK будет в папке bin/
```

### ⚠️ ВАЖНО для Android

**Проблема**: На Android приложение работает в оффлайн режиме?

**Решение**: API ключ должен вводиться через настройки в приложении, а не через .env файл!

**Подробная инструкция**: См. файл [ANDROID_FIX.md](ANDROID_FIX.md)

**Краткое решение**:
1. Запустите приложение на Android
2. Перейдите во вкладку "Настройки"
3. Введите ваш API ключ OpenRouter
4. Нажмите "Сохранить настройки"
5. Попробуйте сгенерировать тест

## 🎯 Как пользоваться приложением

### Генерация нового теста
1. На главном экране введите тему (например, "История России")
2. Выберите сложность (легкий/средний/сложный)
3. Нажмите "Генерировать"
4. Прочитайте теоретический материал
5. Начните тест

### Прохождение теста
1. Выберите вариант ответа
2. Сразу увидите результат (правильно/неправильно)
3. Автоматический переход к следующему вопросу
4. В конце - общий результат

### Сохраненные курсы
1. Перейдите во вкладку "Сохраненные"
2. Выберите любой ранее сгенерированный курс
3. Пройдите тест снова

## 🔑 Получение API ключа OpenRouter

1. Зайдите на https://openrouter.ai
2. Зарегистрируйтесь
3. Перейдите в раздел Keys: https://openrouter.ai/keys
4. Создайте новый ключ
5. Скопируйте ключ (начинается с `sk-or-v1-...`)
6. **На компьютере**: добавьте в `.env` файл
7. **На Android**: введите в настройках приложения

## 🐛 Известные проблемы и решения

### Проблема: "Оффлайн режим" на Android
**Причина**: API ключ не передается  
**Решение**: См. [ANDROID_FIX.md](ANDROID_FIX.md)

### Проблема: SSL ошибки
**Причина**: Проблемы с сертификатами на Android  
**Решение**: Код автоматически повторяет без SSL

### Проблема: Часы не обновляются
**Причина**: Метод `on_enter` может не вызываться  
**Решение**: Используется `on_kv_post` и автоматический старт
