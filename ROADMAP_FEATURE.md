# Обучающие дорожные карты (Roadmaps) - Техническая документация

## Обзор функциональности

Система дорожных карт в SmartTest предназначена для формирования структурированного образовательного пути по комплексным темам. В отличие от одиночных учебных материалов, дорожная карта представляет собой иерархическую структуру модулей, где доступ к последующим этапам открывается только после успешного освоения предыдущих.

## Архитектура системы

### 1. Генерация графа обучения
За формирование структуры отвечает функция `generate_learning_roadmap` в модуле `llm.py`. 
- **Модели**: В качестве основной используется `google/gemini-2.0-flash-exp:free`, обладающая развитыми способностями к логическому структурированию информации. При необходимости система переключается на альтернативные модели.
- **Параметры**: Генерация учитывает базовую тему, цели пользователя и его текущий уровень подготовки.
- **Структура**: Результатом работы является JSON-объект, содержащий массив модулей с уникальными идентификаторами и списком зависимостей (пререквизитов).

### 2. Визуализация и интерфейс
Интерфейс `RoadmapScreen` обеспечивает интерактивное взаимодействие с учебным планом.
- **Отрисовка узлов**: Каждый модуль представлен в виде графического узла (`RoadmapNode`). Узлы размещаются в динамической сетке.
- **Связи**: Взаимосвязи между модулями отрисовываются в методе `update_canvas_lines` с использованием инструкций `Line` на Kivy Canvas.
- **Навигация**: Поддерживается плавное перемещение по карте через `ScrollView`.

### 3. Управление прогрессом
Состояние обучения сохраняется в локальном файле `roadmaps.json`.
- **Статусы**: Каждый модуль может находиться в одном из трех состояний: "Не начат" (заблокирован), "Доступен" (в процессе), "Завершен".
- **Условия перехода**: Модуль переходит в статус "Завершен" после прохождения финального тестирования. Это событие автоматически инициирует проверку зависимостей и разблокировку связанных модулей.

## Технические характеристики

### Хранение данных
Данные сериализуются в формате JSON и хранятся в директории пользовательских данных устройства. Это обеспечивает сохранность прогресса между сессиями работы приложения.

### Сетевое взаимодействие
Учитывая сложность генерации многоуровневых программ, таймауты для этих запросов установлены на уровне 120 секунд. Система использует многослойную архитектуру запросов (Java/urllib/Requests) для обеспечения максимальной стабильности на различных платформах.

## Troubleshooting

### Ошибка: "Request timeout"

**Решение:** Таймауты уже увеличены до 120s. Если всё равно таймаут:
- Проверьте интернет-соединение
- Попробуйте упростить тему
- Уменьшите количество модулей (в промпте)

### Ошибка: "API ключ не найден"

**Решение:**
1. Откройте Settings
2. Введите ключ OpenRouter
3. Нажмите "Сохранить настройки"

### Дорожная карта не отображается

**Решение:**
- Проверьте логи: `[LLM]` и `[MAIN]`
- Убедитесь, что roadmap содержит модули
- Проверьте файл `roadmaps.json` в `user_data_dir`

### Модули расположены некорректно

**Решение:** В `RoadmapScreen._create_roadmap_layout()` настройте:
- `node_width` / `node_height` - размер узла
- `h_spacing` / `v_spacing` - расстояния
- `cols` - количество колонок

## API Reference

### generate_learning_roadmap()

```python
def generate_learning_roadmap(
    topic: str,
    goal: str = None,
    level: str = "начинающий",
    api_key: str = None
) -> dict
```

**Параметры:**
- `topic` - основная тема обучения
- `goal` - цель обучения (опционально)
- `level` - уровень: "начинающий", "средний", "продвинутый"
- `api_key` - ключ OpenRouter API

**Возвращает:**
- dict с дорожной картой или `{"error": "..."}`

### RoadmapNode

Виджет узла дорожной карты.

**Свойства:**
- `node_id` - уникальный ID
- `node_title` - название модуля
- `node_description` - описание
- `status` - "not_started", "in_progress", "completed"
- `node_type` - "main", "optional"

**Методы:**
- `_update_appearance()` - обновление цветов
- `_update_type_text()` - обновление текста типа

### RoadmapScreen

Экран визуализации дорожной карты.

**Методы:**
- `load_roadmap(roadmap_data)` - загрузка и отображение
- `_create_roadmap_layout(canvas, modules)` - создание раскладки
- `on_node_click(module)` - обработчик клика
- `show_module_details(module)` - показ деталей модуля
- `_start_module_learning(module, popup)` - начало обучения
