## Как использовать

### Тестирование функции LLM

```bash
python test_roadmap.py
```

Скрипт запросит API ключ (если не установлен в env) и сгенерирует дорожную карту для темы "Python программирование".

### В приложении

1. Откройте SearchScreen (таб "Поиск")
2. Введите тему: например "JavaScript для начинающих"
3. Выберите режим "🗺️ Программа обучения"
4. Установите сложность: "Легкий", "Средний" или "Эксперт"
5. Нажмите "НАЧАТЬ ОБУЧЕНИЕ"

Приложение:
- Перейдёт на LoadingScreen
- Сгенерирует дорожную карту через LLM
- Сохранит в `roadmaps.json`
- Отобразит на RoadmapScreen

### На RoadmapScreen

- **Просмотр:** Прокручивайте карту, видите модули и связи
- **Детали:** Кликните на модуль → popup с деталями
- **Начать:** В popup нажмите "Начать изучение" → генерация первой темы модуля

## Troubleshooting

### Ошибка: "Request timeout"

**Решение:** Таймауты уже увеличены до 120s. Если всё равно таймаут:
- Проверьте интернет-соединение
- Попробуйте упростить тему
- Уменьшите количество модулей (в промпте)

### Ошибка: "API ключ не найден"

**Решение:**
1. Откройте Settings
2. Введите ключ OpenRouter
3. Нажмите "Сохранить настройки"

### Дорожная карта не отображается

**Решение:**
- Проверьте логи: `[LLM]` и `[MAIN]`
- Убедитесь, что roadmap содержит модули
- Проверьте файл `roadmaps.json` в `user_data_dir`

### Модули расположены некорректно

**Решение:** В `RoadmapScreen._create_roadmap_layout()` настройте:
- `node_width` / `node_height` - размер узла
- `h_spacing` / `v_spacing` - расстояния
- `cols` - количество колонок

## API Reference

### generate_learning_roadmap()

```python
def generate_learning_roadmap(
    topic: str,
    goal: str = None,
    level: str = "начинающий",
    api_key: str = None
) -> dict
```

**Параметры:**
- `topic` - основная тема обучения
- `goal` - цель обучения (опционально)
- `level` - уровень: "начинающий", "средний", "продвинутый"
- `api_key` - ключ OpenRouter API

**Возвращает:**
- dict с дорожной картой или `{"error": "..."}`

### RoadmapNode

Виджет узла дорожной карты.

**Свойства:**
- `node_id` - уникальный ID
- `node_title` - название модуля
- `node_description` - описание
- `status` - "not_started", "in_progress", "completed"
- `node_type` - "main", "optional"

**Методы:**
- `_update_appearance()` - обновление цветов
- `_update_type_text()` - обновление текста типа

### RoadmapScreen

Экран визуализации дорожной карты.

**Методы:**
- `load_roadmap(roadmap_data)` - загрузка и отображение
- `_create_roadmap_layout(canvas, modules)` - создание раскладки
- `on_node_click(module)` - обработчик клика
- `show_module_details(module)` - показ деталей модуля
- `_start_module_learning(module, popup)` - начало обучения
