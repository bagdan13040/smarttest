# Руководство по дизайну и UI/UX (Design Guidelines)

## Визуальная концепция

Интерфейс приложения SmartTest базируется на библиотеке KivyMD, что обеспечивает следование принципам материального дизайна (Material Design). Основная цель дизайна — минимизация когнитивной нагрузки на пользователя во время обучения.

## Цветовая палитра и темы

Приложение поддерживает динамическую смену тем (светлая/темная).
- **Primary Color**: Синий (#2196F3) — используется для основных акцентных элементов, активных кнопок и заголовков.
- **Success Color**: Зеленый — индикация пройденных курсов и правильных ответов.
- **Error Color**: Красный — индикация ошибок и критических уведомлений.
- **Background**: Адаптивный цвет (светло-серый в светлой теме, глубокий сине-черный в темной).

## Типографика

Используются стандартные шрифты системы. Ключевые требования:
- **Заголовки**: Крупный начертание, стиль 'H5' или 'H6' из KivyMD.
- **Текст теории**: Размер 16sp для комфортного чтения больших блоков текста.
- **Кнопки**: Весь текст на кнопках приводится к верхнему регистру (UPPERCASE) в соответствии с гайдлайнами Material Design.

## Элементы интерфейса

### 1. Карточки (MDCard)
Используются для отображения сохраненных курсов и модулей в дорожных картах. Карточки должны иметь небольшое скругление углов (8-12dp) и легкую тень.

### 2. Кнопки (MDRaisedButton)
Все ключевые действия (Начать, Сохранить, Генерация) реализуются через поднятые кнопки with заливкой. Вторичные действия (Отмена) — через плоские кнопки (MDFlatButton).

### 3. Поля ввода (MDTextField)
Должны иметь четкие подсказки (hint_text) и валидацию данных (особенно для поля API ключа).

## Анимации и отклики

- **Переходы между экранами**: Используется `SlideTransition` или `FadeTransition` для обеспечения плавности.
- **Загрузка данных**: Во время работы API всегда отображается индикатор `MDSpinner` или специализированный экран загрузки с динамическим текстом.

## Гайдлайны для Roadmaps

При отрисовке графа обучения необходимо соблюдать следующие правила:
- Расстояние между узлами должно быть достаточным для исключения наложений.
- Линии связей должны иметь толщину 2px и цвет, контрастирующий с фоном.
- Текущий доступный модуль должен пульсировать или выделяться рамкой.
