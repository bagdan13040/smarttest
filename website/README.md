# Skill Flow Landing Page

Это статический лендинг для приложения Skill Flow.

## Как просмотреть
Просто откройте `index.html` в любом современном браузере.

## Технологии
- HTML5 / CSS3
- [Tailwind CSS](https://tailwindcss.com) (через CDN)
- Google Fonts (Inter)

## Структура
- `index.html` — основная страница со всеми секциями (Hero, Features, Roadmaps, Personalization).
- Стили и логика (через CDN) включены в файл для максимальной простоты развертывания.
