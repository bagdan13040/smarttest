# SmartTest

Мобильное приложение для адаптивного обучения с использованием искусственного интеллекта.

## Описание

SmartTest — это интеллектуальная платформа для обучения, которая генерирует персонализированные учебные материалы и тесты по любой теме с помощью LLM (Language Model). Приложение автоматически адаптирует сложность на основе результатов пользователя, обеспечивая оптимальный темп обучения.

### Ключевые возможности

- AI-генерация контента - создание теории и вопросов по любой теме. Система анализирует запрос и формирует структурированный учебный лонгрид с последующим тестированием.
- Дорожные карты обучения (Roadmaps) - создание комплексных программ обучения из нескольких модулей. Каждый модуль представляет собой отдельную тему, а прогресс отслеживается визуально в виде интерактивного графа.
- Адаптивная сложность - алгоритм оценивает процент правильных ответов и автоматически предлагает перейти на уровень выше или повторить материал на более легком уровне.
- Три типа тестирования:
  - Multiple Choice (MC) - классические вопросы с 4 вариантами ответов для проверки базовых знаний.
  - Open-ended - открытые вопросы, где пользователь пишет ответ текстом. AI оценивает смысл ответа, а не просто совпадение слов.
  - Vision - уникальная функция анализа изображений. Позволяет загрузить скриншот или фото учебника, по которому AI сгенерирует пояснения или тест.
- Хранение и прогресс - все курсы и дорожные карты сохраняются локально в JSON-формате, что позволяет возвращаться к обучению в любое время.
- Мобильная платформа - приложение разработано на Kivy и KivyMD, обеспечивая нативный опыт на Android и поддержку Desktop (Windows/Linux/macOS).
- Предзагрузка - для минимизации ожидания открытые вопросы генерируются в фоновом режиме, пока пользователь проходит основную часть теста.

## Быстрый старт

### Требования

- Python 3.10+
- pip
- Виртуальное окружение (рекомендуется)

### Установка

1. Клонируйте репозиторий:
```bash
git clone <repository-url>
cd context_study
```

2. Создайте виртуальное окружение:
```bash
python -m venv .venv
```

3. Активируйте окружение:
```bash
# Windows
.venv\Scripts\activate

# Linux/Mac
source .venv/bin/activate
```

4. Установите зависимости:
```bash
pip install -r requirements.txt
```

5. Запустите приложение:
```bash
python main.py
```

## 🎮 Использование

### 1. Настройка API ключа

При первом запуске:
1. Перейдите в раздел **⚙️ Настройки**
2. Введите API ключ для LLM сервиса
3. Нажмите **Сохранить**

### 2. Создание курса

1. Перейдите в раздел Поиск.
2. Введите название темы (например, "Python основы").
3. Выберите уровень сложности:
   - Легкий - базовые концепции и определения.
   - Средний - погружение в детали и практические примеры.
   - Эксперт - продвинутые темы и нюансы реализации.
4. Нажмите Начать обучение. Приложение сгенерирует теорию и проверочные задания в режиме реального времени.

### 3. Прохождение теста

Процесс обучения состоит из четырех этапов:
1. Теория: Изучение материала. Система использует Kivy Markup для качественного отображения текста.
2. MC тест: Тест с вариантами ответов. Помогает закрепить фактологическую информацию.
3. Развёрнутые ответы: AI оценивает ваш текстовый ответ по шкале от 0 до 10, учитывая смысл и ключевые факты.
4. Финальный отчёт: Сводная статистика, отражающая ваш бал и указывающая на пробелы в знаниях.

### 4. Повторный доступ к материалам

Все успешно сгенерированные курсы сохраняются в памяти устройства:
1. Перейдите в раздел Сохранённые.
2. Выберите нужный материал из списка.
3. Процесс обучения можно начать заново без повторного обращения к Интернет-соединению (если курс уже был загружен полностью).

## Ключевые особенности

### 1. Предзагрузка контента

Для обеспечения плавности переходов между этапами обучения используется система фоновой предзагрузки. Пока пользователь проходит тест с вариантами ответов, приложение в отдельном потоке обращается к AI для генерации открытых вопросов или извлекает их из кеша. Это позволяет избежать экранов загрузки в середине процесса.

### 2. Интеллектуальное кеширование

Все сгенерированные материалы (теория, тесты, дорожные карты) сохраняются в локальной базе данных. Повторный запрос по аналогичной теме и сложности не требует обращения к API, что экономит трафик и время пользователя.

### 3. Адаптивная сложность

Алгоритм оценки знаний анализирует успеваемость пользователя. При стабильно высоких результатах (более 80%) приложение предлагает повысить уровень сложности для следующей темы. В случае трудностей (менее 40% верных ответов) сложность автоматически снижается до базовой.

### 4. Комбинированная отчётность

Финальные результаты объединяют количественную оценку (процент верных ответов в тесте) и качественную оценку (анализ AI развернутых ответов). Пользователь получает подробный фидбек по каждой ошибке с пояснениями.

### 5. Асинхронная архитектура

Все ресурсоемкие задачи, такие как сетевые запросы к LLM, рендеринг сложных графов и оценка ответов, выполняются асинхронно. Это гарантирует, что интерфейс приложения будет оставаться отзывчивым даже при медленном Интернет-соединении.

## Разработка

### Запуск в режиме разработки

Для запуска на ПК необходимо активировать виртуальное окружение и запустить основной скрипт main.py. В консоль будут выводиться логи работы LLM модуля и менеджера экранов.

### Настройка интерфейса

Пользовательский интерфейс описан с использованием языка KV. Это позволяет легко изменять стили, размеры и расположение элементов без переписывания логики на Python.

### Модификация логики AI

Все промпты и алгоритмы взаимодействия с нейросетями сосредоточены в модуле llm.py. Здесь можно настроить поведение учителя, изменить требования к генерации теории или добавить новые модели нейросетей.
