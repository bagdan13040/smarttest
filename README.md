# SmartTest 🎓

Мобильное приложение для адаптивного обучения с использованием искусственного интеллекта.

## 📖 Описание

**SmartTest** — это интеллектуальная платформа для обучения, которая генерирует персонализированные учебные материалы и тесты по любой теме с помощью LLM (Language Model). Приложение автоматически адаптирует сложность на основе результатов пользователя, обеспечивая оптимальный темп обучения.

### ✨ Ключевые возможности

- 🤖 **AI-генерация контента** - создание теории и вопросов по любой теме.
- 🗺️ **Дорожные карты обучения** - создание комплексных программ обучения из нескольких модулей с отслеживанием прогресса.
- 📊 **Адаптивная сложность** - автоматическая подстройка уровня (легкий → средний → эксперт).
- ✅ **Три типа тестирования**:
  - Multiple Choice (MC) - вопросы с вариантами ответов.
  - Open-ended - развёрнутые ответы с AI-оценкой.
  - Vision - анализ изображений и генерация вопросов по ним.
- 💾 **Хранение и прогресс** - сохранение курсов и дорожных карт в локальное хранилище.
- 📱 **Мобильная платформа** - оптимизировано для Android (Kivy + KivyMD).
- 🎨 **Современный UI** - плавные переходы, анимации и визуализация учебных модулей.
- 🔄 **Предзагрузка** - интеллектуальная фоновая генерация для минимизации ожиданий.

## 🚀 Быстрый старт

### Требования

- Python 3.10+
- pip
- Виртуальное окружение (рекомендуется)

1. **Клонируйте репозиторий**:
```bash
git clone <repository-url>
cd context_study
```

2. **Создайте виртуальное окружение**:

3. **Активируйте окружение**:
```bash

source .venv/bin/activate
```

4. **Установите зависимости**:
```bash
pip install -r requirements.txt
```

5. **Запустите приложение**:
```bash
python main.py
```

## 🎮 Использование

### 1. Настройка API ключа

При первом запуске:
1. Перейдите в раздел **⚙️ Настройки**
2. Введите API ключ для LLM сервиса
3. Нажмите **Сохранить**

### 2. Создание курса

1. Перейдите в **🔍 Поиск**
2. Введите название темы (например, "Python основы")
3. Выберите уровень сложности:
   - 🟢 **Легкий** - базовые концепции
   - 🟡 **Средний** - средний уровень
   - 🔴 **Эксперт** - продвинутые темы
4. Нажмите **Начать обучение**

### 3. Прохождение теста

**Этап 1: Теория**
- Изучите сгенерированный материал
- Нажмите **Начать тест** когда будете готовы

**Этап 2: MC тест**
- Ответьте на вопросы с вариантами ответов
- Получите мгновенную обратную связь
- Приложение автоматически предзагружает следующий этап

**Этап 3: Развёрнутые ответы**
- Напишите развёрнутые ответы на вопросы
- AI оценит ваши ответы по шкале 0-10
- Получите рекомендации по улучшению

**Этап 4: Финальный отчёт**
- Просмотрите результаты обеих частей
- Изучите работу над ошибками
- Получите рекомендации для дальнейшего изучения

### 4. Повторное прохождение

Все курсы сохраняются автоматически:
1. Перейдите в **💾 Сохранённые**
2. Выберите курс из списка
3. Пройдите тест заново

## ⚡ Ключевые особенности

### 1. Предзагрузка контента

Открытые вопросы генерируются в фоне во время прохождения MC теста, что обеспечивает плавный переход между этапами без задержек.

```python
# Запускается при входе на QuizScreen
threading.Thread(target=app.preload_open_questions, daemon=True).start()
```

### 2. Интеллектуальное кеширование

Приложение кеширует сгенерированные вопросы для каждой комбинации темы и сложности, избегая повторных запросов к LLM.

```python
cache_key = f"{topic.lower()}|{difficulty}"
```

### 3. Адаптивная сложность

Система автоматически регулирует уровень сложности:
- **≥80% правильных** → повышение уровня
- **≤40% правильных** → понижение уровня

### 4. Комбинированная отчётность

Финальный экран объединяет результаты MC теста и развёрнутых ответов в единый отчёт с визуальным разделением секций.

### 5. Асинхронная обработка

Все долгие операции (генерация, оценка) выполняются в отдельных потоках, не блокируя пользовательский интерфейс.

## 🔧 Разработка

### Запуск в режиме разработки

```bash
# Активируйте окружение
.venv\Scripts\activate

# Запустите с debug логами
python main.py
```

### Проверка синтаксиса

```bash
python -m py_compile main.py
```

### Модификация UI

Большая часть UI описана в KV-разметке внутри `main.py` (строка ~320+). Kivy поддерживает hot reload при правильной настройке.

### Добавление нового экрана

1. Создайте класс экрана:
```python
class NewScreen(Screen):
    pass
```

2. Добавьте в ScreenManager (KV):
```python
ScreenManager:
    MainScreen:
    NewScreen:
    ...
```

3. Определите разметку:
```python
<NewScreen>:
    name: 'new_screen'
    BoxLayout:
        # Your UI here
```

### Модификация LLM промптов

Все промпты находятся в `llm.py`. Измените их для настройки поведения генерации контента.
