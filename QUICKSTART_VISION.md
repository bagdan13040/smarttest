# Быстрый старт - AI Vision Chat

## Описание функции

В приложении реализована возможность визуального анализа изображений. Вы можете выбирать фотографии из галереи Android или файлы на Desktop для отправки в AI чат. Нейросеть проанализирует изображение и ответит на ваши вопросы.

## Как использовать

1. На главном экране нажмите кнопку вызова AI чата.
2. Для прикрепления изображения используйте кнопку выбора файла.
3. После выбора изображения иконка изменится, подтверждая готовность к отправке.
4. Вы можете задать текстовый вопрос к изображению или отправить его для автоматического описания.
5. Нажмите кнопку отправки для получения результата от нейросети.

## Технические подробности

### Поддерживаемые платформы
- Android: используется интеграция с нативной галереей через Intent API.
- Desktop Windows/macOS/Linux: используется нативный выбор файлов.

### Поддерживаемые форматы
Приложение корректно обрабатывает основные графические форматы: JPG, JPEG, PNG, GIF, WEBP, BMP.

## Примеры использования

### 1. Образовательные задачи
- Анализ графиков и диаграмм из учебников.
- Пояснение сложных схем и иллюстраций.
- Распознавание и решение математических уравнений по фотографии.

### 2. Техническая помощь
- Анализ скриншотов кода для поиска ошибок.
- Описание архитектурных диаграмм.
- Конвертация текста с фотографий документов в текстовый формат.

## Настройка

Для работы функции необходимо:
1. Иметь стабильное Интернет-соединение.
2. Настроить API ключ OpenRouter в настройках приложения.
3. Предоставить приложению доступ к файловому хранилищу устройства при первом запросе.
1. `google/gemini-2.0-flash-exp:free` (основная)
2. `qwen/qwen-2-vl-7b-instruct:free` (запасная 1)
3. `meta-llama/llama-3.2-11b-vision-instruct:free` (запасная 2)

Если одна модель недоступна (429 error), автоматически переключается на следующую.

## 🔧 Решение проблем

### "API ключ не настроен"
➡️ Сохраните ключ в Настройках → API Ключ OpenRouter

### File picker не открывается (Android)
➡️ При первом использовании разрешите доступ к файлам в диалоге Android

### "Too Many Requests" (429)
➡️ Бесплатные модели имеют лимиты, подождите 5-10 минут или система переключится на другую модель

### Изображение не отправляется
➡️ Проверьте:
- Есть ли API ключ
- Есть ли интернет
- Размер файла (рекомендуется до 2-3 MB)
